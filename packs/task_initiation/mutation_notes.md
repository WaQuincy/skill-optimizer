# Task Initiation Mutation Notes

Prefer conservative edits that make Task Initiation more reliable without changing its identity.

- Preserve all phases and completion rules unless the benchmark shows a specific ambiguity.
- Strengthen one-question discipline when weak scenarios show over-questioning.
- Strengthen blocker-specific interventions when the coach gives generic advice.
- For `too_big`, the coach must pick exactly one visible physical first action. It must not ask the user to invent or choose the action.
- For `decision_paralysis`, the coach must pick one named task for the user. It must not ask which task they want to focus on.
- Strengthen handoff rules for emotional flooding and unrelated requests.
- Keep first actions physical, visible, and small enough for 2-10 minutes.
- Do not add task creation, reminders, calendar actions, or app object updates.
- Do not convert this skill into day planning, project review, or emotional processing.
